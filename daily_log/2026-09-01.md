## 11:59 — Signal Scout Milestone 1 implementation design

Rewrote Milestone 1 as a safe anonymous public-web runtime with exact Hermes
integration and file boundaries. Signal Scout remains one self-contained
`plugins/signal-scout/` plugin: one `signal_scout` model tool, one operator CLI,
`pre_tool_call`/`post_tool_call`/`on_session_end` hooks, one explicit research
skill, plugin-owned SQLite/artifacts, deterministic checkpoints, and generated
JSON/Markdown reports. Policy is session-scoped and default-deny; Milestone 1
allows only direct public navigation and passive page inspection. Click, type,
keypress, JavaScript, terminal, file, messaging, MCP, delegation, cron, and
other write-capable tools remain blocked.

Hermes already provides untrusted framing for web/browser results, so Signal
Scout reuses and tests it rather than adding a result-transform hook. Retrieval
captures are bounded and redacted; evidence must reference a prior capture and
text excerpts must occur inside it. Added a deterministic tool-call ceiling for
development without presenting it as the unresolved 50-percent Codex budget.
Checkpoint cadence no longer depends on that budget source.

Production local-browser isolation has one unresolved deployment requirement:
a plugin preflight cannot stop Chromium redirects or DNS rebinding from reaching
private networks. Real public-web missions require a verified second-machine
egress boundary (guest VLAN/firewall or strict proxy/container). Controlled
fixtures can proceed before that mechanism is selected. Updated
`signal-scout/stuff/milestones.md` and bumped `stuff/specs.json` to schema v2.
